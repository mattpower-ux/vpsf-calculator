# Learn More Narration Scripts

One plain-text, recording-ready script for each calculator recommendation's
Learn More page other than HVAC + Smart Controls. The HVAC script is in
`../hvac-pilot/src/content.json` and has already been recorded.

Each file follows the calculator's current Background, supporting educational
sections, and recommendation details. Paragraph breaks mark natural pauses;
the files contain no titles or production directions to be spoken aloud.

The scripts target roughly the 47-second pace of the HVAC pilot. Final duration
will depend on the chosen voice and delivery, so time each recording before
animating a video to it.
