# HVAC + Smart Controls Pilot

Remotion source for the calculator's HVAC Learn More video. The narration is
`public/audio/hvac-overview.mp3`; scene copy and durations are in `src`.

```sh
npm install
npm run lint
npx remotion render HvacSmartControls out/hvac-smart-controls.mp4
```

The deployed, mobile-optimized export and poster live in
`frontend/public/videos/`. Render again and replace those files when editing
the video. Check the [Remotion license](https://www.remotion.dev/docs/license/pricing)
before commercial production use.
